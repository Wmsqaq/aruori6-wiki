官方介绍 （Modrinth · 中文版由 GLM AI 翻译，仅供参考）

     

Permanent Sponges（永久海绵）新增了几款实用的新海绵：它们不仅能清除液体，还能把液体永久挡在外面！准备好建造没有天花板的疯狂海底城市了吗？

  • 轻松清除大范围内的液体！
  • 只要海绵还在，液体就进不来，也流不回去。
  • 还包含一款专为熔岩和其他高温流体设计的岩浆海绵。
  • 还有插在木棍上的海绵棒，可以快速清理小范围的液体。

⏩ 客户端与服务器端均需安装

⏩ 需要安装 PUZZLES LIB（FABRIC & NEOFORGE）

⏩ 需要安装 FABRIC API（FABRIC）

⏩ 需要安装 FORGE CONFIG API PORT（FABRIC）

如果模组支持配置，可以直接在游戏内通过模组菜单进行配置（在 Fabric 上需要安装 Prospector 制作的 Mod Menu）。

如需使用外部文本编辑器手动配置，所有配置文件位于 .minecraft/config，按配置类型命名为 MOD_ID-client.toml、MOD_ID-common.toml 或 MOD_ID-server.toml。具体取决于配置类型。并非每个模组都有全部类型的配置文件，甚至可能一个都没有。

🌟 感谢 Jackyy 及其 Simple Sponges 模组，正是本模组的灵感来源。

🌟 感谢 Nyffuuuh23 制作的那些精美材质！

Permanent Sponges adds some neat new sponges that don't just remove liquids, but also keep them away permanently! Ready to build some crazy underwater cities without ceilings?

  • Clear out liquids with ease in a big area!
  • Liquids will stay away and are not able to flow back as long as the sponge remains.
  • Includes a magmatic sponge made specially for lava and other hot fluids.
  • There are also sponges on sticks, for quickly clearing out some small pockets of fluids.

⏩ INSTALLATION REQUIRED ON CLIENT & REQUIRED ON SERVER

⏩ REQUIRES PUZZLES LIB TO BE INSTALLED (FABRIC & NEOFORGE)

⏩ REQUIRES FABRIC API TO BE INSTALLED (FABRIC)

⏩ REQUIRES FORGE CONFIG API PORT TO BE INSTALLED (FABRIC)

If available for a mod, configuration is possible directly from in-game using the mod menu (requires Mod Menu by Prospector to be installed on Fabric).

For manual configuration using an external text editor all files are found at .minecraft/config, named as MOD_ID-client.toml, MOD_ID-common.toml, or MOD_ID-server.toml, depending on the type of config. Not all types might exist for a mod, if any at all.
