Iron's Lib 是一个库模组，为我的模组提供易于复用的框架，还包含一层 Patreon 集成 API。

外观变形（Transmog）

  • 为物品应用独特的盔甲模型
  • 高度可自定义的盔甲界面
  • 自动处理披风物理效果

雕像

  • 动态生成玩家雕像资源
  • 动态多方块处理
  • 静态模型渲染

属性

  • 轻量且无侵入地实现常见 RPG 风格属性
    • 护甲穿透、挖掘速度、经验获取、箭矢伤害、暴击伤害、闪避几率、受到治疗、弹射物伤害
  • 属性重映射器（Attribute Remapper），可在游戏内动态热替换物品属性，实现最大兼容性
    • 与 Apothic Attributes 原生兼容
    • 同时提供代码与数据包入口点

动能武器（长矛）组件向下移植 * 在 1.20.1 和 1.21.1 上，完整对等地向下移植了长矛的蓄力攻击组件套件（kinetic_weapon、use_effects、attack_range）。 * 超越原版之处在于，还包含 KineticAnimation 接口，用于自定义第一/第三人称蓄力动画

灵魂火燃烧

  • 轻量且仅影响视觉的灵魂火燃烧实现
  • 将生物的下一次燃烧标记为灵魂火，它就会烧出蓝色的火焰

Patreon 集成

  • 为上述所有功能提供 Patreon 集成服务

Iron's Lib is a library adding easy-to-reuse frameworks for my mods, as well as a Patreon Integration API layer.

Transmogs

  • Apply unique armor models to items
  • Highly customizable Armor interfaces
  • Automatic cape physics handling

Statues

  • Dynamic Player statue asset generation
  • Dynamic multiblock handling
  • Static model rendering

Attributes

  • Lightweight and non-intrusive implementation of common RPG-style attributes
    • Armor Pierce, Mining Speed, Experience Gained, Arrow Damage, Crit Damage, Dodge Chance, Healing Received, Projectile Damage
  • Attribute Remapper to dynamically hotswap item attributes in game for maximum compatibility
    • Native compat with Apothic Attributes
    • Entrypoints for both code and datapacks

Kinetic Weapon (Spear) Component Backport * On 1.20.1 and 1.21.1, adds a full-parity backport of the spear's charge attack component suite (kinetic_weapon, use_effects, attack_range). * Surpassing vanilla, also includes a KineticAnimation interface for custom first or third person charge animations

Soul Fire Burning

  • Lightweight and visual-only Soul Fire Burning implementation
  • Mark a creature's next burn as soul fire, and they will burn blue

Patreon Integration

  • Patreon integration services for all of the above features
